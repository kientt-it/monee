# UI/UX

Mobile-first với tham chiếu 375/390/430px. Bottom navigation cố định có safe-area, CTA thêm nằm giữa. Card radius 20px, button radius 14px, touch target tối thiểu 44px.

Visual direction: xanh lá sâu và nền sáng dịu, ưu tiên cảm giác bình tĩnh, rõ ràng. Main body >=16px; tiền dùng tabular nums. Màu không phải tín hiệu duy nhất; trạng thái cần text/icon.

Form về sau dùng React Hook Form + Zod. Filter/account/category trên mobile ưu tiên bottom sheet; desktop dùng dialog/popover.
